📖 Overview
The Payroll Management System is a C++ application that simplifies the complex task of managing employee payroll. It allows HR personnel and administrators to maintain employee records, calculate salaries with all applicable deductions and bonuses, and generate professional payslips — all from a simple console-based interface backed by file storage for data persistence.

✨ Features

✅ Add, view, update, and delete employee records
✅ Salary calculation (hourly or fixed/monthly basis)
✅ Automatic tax deduction computation
✅ Provident Fund (PF) and other deduction handling
✅ Overtime and bonus calculation
✅ Individual payslip generation
✅ Search employee by ID or name
✅ Display all employee records
✅ Data persistence using file handling (.txt / .dat)
✅ Admin login with password protection

🧩 Modules
1. Employee Management

Add new employees with details such as ID, name, designation, department, and basic salary.
Update or delete existing records.

2. Salary Calculation

Computes gross salary from basic pay, allowances, and overtime.
Deducts taxes, provident fund, and other applicable deductions.
Calculates net take-home salary.

3. Payslip Generation

Generates a detailed payslip for each employee showing:

Earnings breakdown
Deductions breakdown
Net salary

4. File Handling

All employee records are saved to and loaded from a .dat file for persistence across sessions.

5. Search & Display

Search employees by Employee ID or Name.
Display a list of all employees in a formatted table.
